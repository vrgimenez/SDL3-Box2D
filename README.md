# Hello SDL Graphics And Box2D Physics

![Latest Release](https://shields.io)
![Platform](https://shields.io)

An simple example of integrating Box2D physics with SDL graphics.

## Introduction

The goal is to integrate physics with graphics and have a collection of 'DickButts' fall and collide using real physics.\
I started with separate Hello World examples, and then put everything together.

## Setup 

Checkout repository.
```console
git clone <url>
```

## Building

```console
cmake -Bbuild
cmake --build build/
```
